# 51 串口密码锁

基于 8051 单片机（AT89C52 / STC89C52）的六位数字密码锁，使用 Keil C51 开发。支持 4×4 矩阵键盘输入、8 位数码管显示、AT24C02 掉电保存密码、蜂鸣器与 LED 声光反馈，并可通过 UART 用命令远程操作、读取状态。

## 功能特性

- **6 位密码**：EEPROM 空白时默认密码 `012345`；解锁后可改密，新密码需连续输入两次且一致
- **矩阵键盘**：数字 0–9、清除、取消、确认、删除、改密、上锁
- **8 位数码管**：第 1 位显示状态码，第 2 位显示错误次数，后 6 位显示输入/倒计时，空位显示 `-`
- **防试探**：连续错 3 次进入 WAIT（30 s），错 5 次进入 PROTECT（60 s）；限制状态与错误次数掉电保存
- **自动上锁**：解锁/改密状态下 15 s 无有效操作自动回到锁定
- **声光反馈**：蜂鸣器 + D7 灯按事件播放不同节奏（普通/成功/错误/限制）
- **串口控制**：9600 8N1，支持输入、删除、确认、改密、上锁、查询状态/版本
- **ISP 升级**：解锁状态下发送 `ISP`，500 ms 后软复位进入 STC ISP 下载模式
- **双区密码存储**：改密时先写另一区并回读校验，最后切换区标志，避免掉电写坏密码

## 硬件与引脚

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 矩阵键盘 4×4 | P1 | P1.0–P1.3 列，P1.4–P1.7 行 |
| 数码管段选 | P0 | 共阴段码（0x3F…），经限流电阻 |
| 数码管位选 | P2.2–P2.4 | 3-8 译码选通 8 位 |
| AT24C02 | P2.1 = SCL，P2.0 = SDA | 软件 I2C，器件地址 0xA0 |
| 串口 | P3.0 = RXD，P3.1 = TXD | 9600 bps，8 数据位，无校验，1 停止位 |
| 蜂鸣器 | P2.5 | 高电平响 |
| D7 反馈灯 | P2.6 | 低电平亮 |
| D8 版本灯 | P2.7 | 低电平亮；A 版常暗，B 版常亮 |
| 74HC595 点阵 | P3.4 = SER，P3.6 = SCK，P3.5 = RCK | 预留 8×8 点阵接口，当前未启用 |

- 晶振：**11.0592 MHz**（保证 9600 波特率与 1 ms 定时精度）
- 内核：MCS-51；Keil 工程中器件选 AT89C52
- 工程 Target 里的 24 MHz 只影响软件仿真，实际硬件请用 11.0592 MHz

## 编译与烧录

1. 用 Keil uVision 5（C51）打开 `project.uvproj`，Rebuild。
2. 生成 `Objects/project.hex`。
3. 烧录到 AT89C52 / STC89C52，晶振 11.0592 MHz。
4. `HEX/firmware_A.hex`、`HEX/firmware_B.hex` 为两份预编译固件：
   - A 版：D8 常暗；
   - B 版：D8 常亮。
   两版仅 `main.c` 中 `#define FW_B` 的取值不同。
5. 编译时出现两条 L16 警告（`Delay`、`MatrixLED_ShowColumn` 未被调用）属正常现象。

## 串口协议

- 参数：9600 bps、8 数据位、无校验、1 停止位。
- 每条命令以 `\n` 结尾，`\r` 会被忽略；命令区分大小写。

| 命令 | 作用 |
| --- | --- |
| `DIGIT n` | 输入数字 n（0–9），n 与命令间一个空格 |
| `DEL` | 删除一位 |
| `CLEAR` | 清空当前输入 |
| `OK` | 确认（解锁/改密第一遍/第二遍） |
| `CHANGE` | 进入改密（仅解锁状态） |
| `CANCEL` | 取消 |
| `LOCK` | 立即上锁 |
| `STATUS` | 查询状态 |
| `VERSION` | 查询版本，返回 `OK VERSION 1.0` |
| `ISP` | 解锁状态下进入升级准备，500 ms 后软复位进 ISP |

回复格式：

```text
OK  <S> <N> <E> <R> <I>
ERR <CODE> <S> <N> <E> <R> <I>
```

- `S`：状态，`LOCKED` / `UNLOCKED` / `NEW1` / `NEW2` / `WAIT` / `PROTECT` / `UPGRADE`
- `N`：已输入位数
- `E`：连续错误次数
- `R`：限制状态剩余秒数
- `I`：自动上锁剩余秒数
- `CODE`：`FULL`（已满 6 位）、`DENIED`（当前状态不允许）、`INCOMPLETE`（不足 6 位）、`WRONG`（密码错误）、`STORAGE`（保存失败）、`MISMATCH`（两次新密码不一致）、`BAD_CMD`（非法命令）

示例：

```text
DIGIT 1
OK LOCKED 1 0 0 0
OK
ERR WRONG LOCKED 0 1 0 0
```

## 状态机

| mode | 名称 | 说明 |
| --- | --- | --- |
| 0 | LOCKED | 锁定，可输入密码 |
| 1 | UNLOCKED | 已解锁，15 s 无操作自动上锁 |
| 2 | NEW1 | 输入新密码第一遍 |
| 3 | NEW2 | 再输入一遍确认 |
| 4 | WAIT | 错 3 次，等待 30 s |
| 5 | PROTECT | 错 5 次，保护 60 s |
| 6 | UPGRADE | ISP 升级准备 |

## EEPROM 布局（AT24C02）

| 地址 | 内容 |
| --- | --- |
| 1–6 | 密码区 0 |
| 7 | 当前有效密码区标志（0 或 1） |
| 10 | 连续错误次数 |
| 11 | 限制阶段（4/5，用于掉电恢复） |
| 12–17 | 密码区 1 |

改密流程：写入非当前区 → 逐字节回读校验 → 最后写地址 7 切换区标志。

## 说明

- 源码为 **UTF-8（无 BOM）** 编码，GitHub 上中文注释可正常显示，Keil 可直接打开。
- 默认密码 `012345` 只在 EEPROM 空白（首次使用）时生效；改密后密码保存在 EEPROM 中。
- `ISP` 功能依赖 STC 芯片的 ISP 引导码；AT89C52 不支持，使用 STC89C52 时可用。
